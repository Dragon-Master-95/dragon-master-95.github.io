Tools

Tools &
Open Source.

A collection of small web-based tools and open-source code that grew out of my day-to-day work in radio astronomy, RF instrumentation and space weather. Some run right here in the browser; others live on GitHub as scripts and software you can clone, adapt and build on.

Everything here is shared freely in the hope that it saves someone else a few hours at the bench or at the telescope. Issues, suggestions and pull requests are always welcome.

Developed with the assistance of Claude (Anthropic), which helped make these tools more user-friendly.
